# EV Market Performance and Insights

## 📌 About the Project
EV Market Performance and Insights is a data analytics project focused on understanding the electric vehicle (EV) market and its performance. The project presents market insights through an interactive Tableau dashboard and a web application.

## 🎯 Objectives
- Analyze electric vehicle market performance.
- Present key insights through data visualization.
- Make EV market information easier to understand.
- Provide an interactive way to explore project insights.

## ✨ Features
- Web application developed using Python and Flask.
- Interactive data visualization using Tableau.
- Easy-to-use website interface.
- Visual presentation of EV market insights.

## 🛠️ Technologies Used
- Python
- Flask
- HTML
- Tableau
- Data Visualization

## ⚙️ How to Run the Project

1. Install Python on your system.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the Flask application:

   ```bash
   python app.py
   ```

6. Open your browser and visit:

   `http://127.0.0.1:5000/`
